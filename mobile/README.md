# Мобильное приложение переехало

WireMap Обход (Android, Expo/React Native) больше не живёт в этом
репозитории — код и вся его история коммитов перенесены в отдельный:

**https://github.com/Sined216/wiremap-mobile**

Причина — приложение самодостаточно (свой `package.json`, своя сборка на
EAS) и не делит зависимости с бэкендом или веб-версией; единственная
связь между ними — файл `backend/openapi.json`, из которого приложение
генерирует типы API (`npm run codegen` там же, см. README нового
репозитория).
